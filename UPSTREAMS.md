- **MoonSharp:** https://github.com/moonsharp-devs/moonsharp, the original Lua interpreter. Its repository identifies the program and libraries as BSD 3-Clause licensed.
- **MoonSharp UnityEnhanced:** https://github.com/SmilingCatEntertainment/moonsharp-unityenhanced, the source for the bounded stack-capacity adaptation and inherited attribution.
- **KopiLua:** https://github.com/NLua/KopiLua, credited for portions of MoonSharp's string library, as noted in the inherited license.
- **Microsoft vscode-mono-debug:** https://github.com/Microsoft/vscode-mono-debug, credited for debugger code, as noted in the inherited license.
- **Eclipse:** https://www.eclipse.org/, credited for remote debugger icons in the inherited license. This source extraction includes no separate MoonFlat icon asset.

The upstream LICENSE itself contains the literal `{organization}` template text in its BSD 3-Clause endorsement clause. MoonFlat preserves that source notice rather than substituting a different organization's name. Review the upstream attribution inventory before making a binary distribution.
